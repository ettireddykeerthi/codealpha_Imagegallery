# 📸 Task 1: Image Gallery

## 📌 Description

This project is a responsive **Image Gallery** created using **HTML, CSS, and JavaScript**.

The gallery allows users to view different images, filter them by category, and open images in a full-screen lightbox view.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Responsive image gallery
- Nature, City, and Animals categories
- Image filtering
- Hover effects
- Smooth transitions
- Lightbox image view
- Next and Previous buttons
- Keyboard navigation
- Escape key to close the image
- Mobile-friendly design

## 📂 Project Structure

```text
Task-1-Image-Gallery/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

1. Open the `Task-1-Image-Gallery` folder.
2. Open the `index.html` file in a web browser.
3. The Image Gallery will be displayed.
4. Click on any image to open it in the lightbox.
5. Use the **Next** and **Previous** buttons to navigate.
6. Use the category buttons to filter images.

## ⌨️ Keyboard Controls

| Key | Function |
|---|---|
| `←` | Previous Image |
| `→` | Next Image |
| `Esc` | Close Image |

## 📱 Responsive Design

The gallery automatically adjusts its layout for:

- Desktop screens
- Tablets
- Mobile phones
